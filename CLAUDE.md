# Claude Code instructions

Read [`AGENTS.md`](AGENTS.md) completely before working in this repository. It is the
provider-neutral canonical source for project commands, Graphify, companion documents,
cross-repo compatibility, completion criteria and review policy. Do not duplicate those
rules here.

Claude Code may enable the optional Graphify hooks by copying
`.claude/settings.example.json` to `.claude/settings.local.json`. The guarded example is a
no-op when Graphify is unavailable.
